# Scorekeeper

Scorekeeper is a score keeping app.
You can find it deployed on [GitHub Pages](https://petermacko90.github.io/scorekeeper/).

Built with Angular, using signals and signal forms. Styled with Tailwind CSS.

## Features

- automatic score counting
- sticky column with round numbers and sticky rows with player names and score sums
- add/remove players
- add/remove rounds
- write/view notes about the game
- reset the board to initial state
- undo certain actions
- move the actions panel to top, bottom, left or right
- responsive layout
- light/dark theme based on browser setting (prefers-color-scheme)
- save the state to local storage
